# MRR Card Game

MARORONG CARD WAR - Phase 21 original game and Phase 22 Three.js visual prototype.

This repository preserves the Phase 21 original. Game rules and card data remain authoritative in the legacy JavaScript engine. Three.js is an optional visual layer, with a CSS fallback.

Development notes and reproducible build/test workflow are included. Phase 22 real WebGL rendering is pending CI verification; no production release is claimed.

Please see README_KO.md for Korean setup instructions.

Phase 23: Three.js field-card hover lift and selection highlight, with a strict Chromium WebGL regression test. Run `python build.py` and inspect the Phase 23 Actions artifact. The legacy Phase 21 and Phase 22 files remain in the repository as unmodified baselines.
