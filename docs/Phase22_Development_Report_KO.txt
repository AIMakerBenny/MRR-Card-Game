기준일: 2026-10-09

1. 수행한 실제 작업

Phase21 HTML을 legacy/Phase21_Original.html에 보존했다.
기존 카드 JSON 데이터와 게임 판정 JavaScript에 변경을 가하지 않았다.
일체형 HTML을 지속적으로 빌드할 수 있게 Python build.py를 만들었다.
기존 HTML에 별도 Three.js 표현 모듈, 3D 전장 토글, CSS 안전 대체 모드를 추가했다.
3D 표현 코드가 DOM에서 현재 공개된 카드와 슬롯 위치만 읽도록 하였다.
WebGL 코드에는 3D 카드 두께와 재질, 슬롯 받침대, 조명, 간단한 피격·회복·소환 링 효과를 작성하였다.
이 3D 코드의 실제 렌더링 성공 여부는 아직 확인되지 않았다.
상용/외부 에셋을 임의 수집하지 않고 절차적 카드 텍스처를 생성하도록 했다.
원본 업데이트는 GitHub에서 버전 관리할 수 있도록 소스 트리와 CI workflow를 준비했다.

2. 검증 완료

STATIC AUDIT PASS - 기존 게임 script 동일, 카드 244개와 진영 10개 유지, 파일 해시 일치.
PARITY PASS - 동일 시드 원본과 수정본의 경기 시작 상태 동일; CSS 입체 모드를 전환해도 상태 동일.
Chromium BROWSER PASS - 1920x1080, 1366x768, 390x844에서 시작과 손패, 30슬롯, 버튼 및 CSS 대체 모드 정상.
Chromium PLACEMENT PASS - 실제 게임 판정으로 합법 카드를 배치한 뒤 손패 감소 한 번, 슬롯 30개 유지.
빌드 성공 및 소스 ZIP 무결성 검증 완료.

6. 정책

테스트가 성공하지 않았는데 완료라고 보고하지 않는다.
