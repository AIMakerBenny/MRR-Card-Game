마로롱 카드 전쟁 Phase21 UI 수정 및 검증 보고서

기준: Phase20 전략 개선본. 카드 규칙과 AI 변경 없음.

수정
1. 손패 호버가 나머지 카드의 좌표와 쌓임 순서를 바꾸지 않도록 수정. 확대 카드만 별도로 표시.
2. 길이 계산에 잘못된 단위 없는 이동값이 들어가지 않도록 수정.
3. 기존 지연 호버가 상세 패널을 열어 전체 손패 중심을 이동시키는 중복 동작 제거.
4. 확대 카드에 능력 이름, 비용, 발동 조건, 효과 원문을 모두 표시. 긴 설명은 내부 스크롤. 실제 마우스 휠로 마지막 능력까지 도달 확인.
5. 설명 배경과 글자 대비 조정.
6. 화면 높이 1000px 경계에 따른 시설 재배치 제거. 시설 칸 최소 높이 44px 확보.
7. 전장 가로 배치와 카드 세로 크기를 가용 공간에 맞게 계산. 시설 가장자리 여유 확보.
8. 한국어 행 이름 가로 표시. 선택하지 않은 상태의 빈 상세 패널 접기.

검증
Chromium headless 브라우저에서 실제 포인터 입력으로 확인.
1920×1080, 1920×999, 1366×768, 2560×1440, 390×844에서 호버 전후 카드 개수와 좌표 분산, 호버 해제 순서 복구, 전체 능력 텍스트, 게임 상태 불변, 자바스크립트 오류 검사 통과.
네 가지 데스크톱 크기에서 카드가 배치된 시설의 상하 경계가 전장 안에 들어오는지 확인.
기존 규칙 회귀 검사 12개 통과.
핵심 판정 검사 통과: 읽기 전용 계획, 다중 대상 처리, 중복 대상 거절, 오래된 대상 거절, 의식 비용과 효과 일괄 처리, 잘못된 의식 거절.
실제 전장 드래그 검사 통과: 불법 드래그의 상태 불변, 합법 공격과 피해 미리보기 일치, 재시작, 저장과 복원, 잘못된 저장 거절.
Phase20과 Phase21의 CARDS 전체 직렬화가 동일함을 확인. 244개 항목, 이름 235종, 10개 진영, 능력 항목 306개.

검증 범위
이번 수정은 UI 오류 수정이다. 3D 모델이나 Godot 실행본을 만들지 않았다.
기존 270경기 전략 검증을 이번 UI 수정 후 재실행하지 않았다.
390px 폭에서는 전장 가로 스크롤과 손패 전체 보기 기능을 사용한다. 모바일 터치의 전체 전투 흐름과 모든 실제 기기 성능은 미검증.
역할 아이콘은 유지했다. 개별 카드의 완성 일러스트는 별도 제작 대상이다.
미지원 능력을 새로 구현하지 않았다. 확대 설명에 등록된 규칙을 보여 주는 변경이다.
